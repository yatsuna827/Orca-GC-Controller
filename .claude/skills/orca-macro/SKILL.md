# MacroScript文法

ORCAマクロはゲームキューブのコントローラ入力を自動化するスクリプトで、1行1コマンドのテキストファイルとして書く。

## 共通規則

- 大文字と小文字を区別する
- 空行はスキップされる
- `#` で始まる行はコメント。行の途中からのコメントは書けない
- 引数は半角スペース1個で区切る（2個以上や全角スペースはエラー）
- オプション引数は `-x=値` の形式（ハイフン+英小文字1字+イコール+値、間にスペース不可）。順序自由だが重複不可

## コマンド

### Press

ボタンを順番に押す。

```
Press <buttons> (-d=200) (-i=0) (-s)
```

- `buttons`: ボタン名のカンマ区切り。`+`で同時押し。カンマの後ろに空白があっても動く
- `-d`: 押下時間（ミリ秒）。省略時200
- `-i`: 各ボタン押下後の待機時間（ミリ秒）。省略時0
- `-s`: 起動するタイマーのラベル（0-9）

```
Press A                      # Aを200ms押す
Press A,A,dU,dU -i=300       # A,A,上,上を300ms間隔で押す
Press B+X -d=100             # BとXを同時に100ms押す
Press B -s=0                 # Bを押すと同時にタイマー0を起動
```

Pressは各ボタンについて「押下→d ms待つ→離す→i ms待つ」を繰り返す。

### Wait

指定ミリ秒だけ待機する。

```
Wait <duration>
```

```
Wait 2000                    # 2秒待機
```

### Start

タイマーを起動する。Hitコマンドがタイミングを計るために使う。

```
Start (-s=0)
```

- `-s`: 起動するタイマーのラベル。省略時0

```
Start                        # タイマー0を起動
Start -s=1                   # タイマー1を起動
```

### Hit

タイマーが指定フレームに達したときにボタンを1回押す。GCの約59.7275fpsに基づいてフレーム数をミリ秒に換算する。

```
Hit <button> <frame> (-l=0) (-c=0) (-d=200) (-s)
```

- `button`: ボタン名1つ（Pressと違いカンマ区切り不可）
- `frame`: 押すタイミング（フレーム数、非負整数）
- `-l`: 参照するタイマーのラベル。省略時0
- `-c`: フレーム補正値（負値可。frame+cが負なら0に切り上げ）
- `-d`: 押下時間（ミリ秒）。省略時200
- `-s`: 起動するタイマーのラベル

Hitより前に、参照先のタイマー（`-l`で指定するもの、省略時はタイマー0）が起動されている必要がある。実行時点で指定フレームを過ぎていれば即座に押す。

```
Start
Hit A 1192                    # タイマー0が1192fに達したらA押下
Hit A 1800 -c=-77             # 1800-77=1723fでA押下
Hit A 500 -l=2 -d=1000 -s=3  # タイマー2の500fでA1秒押下、タイマー3起動
```

## タイマー

ラベル0-9の10個を使える。Start、Press(`-s`)、Hit(`-s`)で起動できる。同じラベルのタイマーを2回起動するとコンパイルエラーになる。

## ボタン名

| ボタン | 記号 |
|---|---|
| A B X Z L R | そのまま |
| Y | `Y` または `Sl` |
| Start | `St` |
| 十字キー上下左右 | `dU` `dD` `dL` `dR` |
| Start+Y同時 | `tl` |

## 典型的な構成

タイミングを合わせる操作（乱数調整など）はStartとHitの組み合わせで書き、メニュー操作のような固定手順はPressとWaitで書く。

```
# メニューを開いてから特定フレームでA
Press St -s=0
Wait 500
Press dD,dD,A -i=200

Start -s=1
Hit A 342 -l=1
```
