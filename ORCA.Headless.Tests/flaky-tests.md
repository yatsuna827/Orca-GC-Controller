# 不安定なテストについての申し送り

- 進捗のポーリング(100ms)が、観測対象の行の実行中に一度も割り込めなかった場合に、意図しない形でテストが落ちてしまう。
  - ただし、これが発生するにはスレッドが400ms-止まる必要があり、この規模の停止が発生し得るのはCPUが飽和したCIランナーなどの環境のみで、開発機では起きることはまずない。
  - もしCI環境などで問題が起きたら、`"parallelizeTestCollections": false`を設定すれば、テスト同士の並列実行を抑制できる
- その他の時間依存（`SpinUntil`と`CompletesWithin`の5000ms、パイプ接続の5000ms、`Press A -d=5000`が完了する前に停止操作が受理される前提のコード）は、スレッドの停止が数秒に及ばないと発生しないので、考えなくていい
